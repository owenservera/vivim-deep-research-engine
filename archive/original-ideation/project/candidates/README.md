# Candidates

Each file here is one non-dead approach from Phase 1, or a pushed-further idea
from Phase 2. Naming: `<short-name>.md`.

Lifecycle markers used in these files:
- `claimed-by: <session-id>` — an extender has reserved this candidate
- `NEEDS WORK: <specific gap>` — a validator flagged an exact gap for an extender
- `READY FOR VALIDATION` — an extender believes it's a real result (validators only)
- `SURVIVED VALIDATION` — a validator could not break it (NOT human confirmation)

This directory starts empty. It is populated by generator and extender agents.
