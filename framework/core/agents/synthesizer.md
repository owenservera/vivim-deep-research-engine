# Synthesizer Agent — Master Definition

**Role:** Write up verified results clearly. Internal consistency check.  
**Ratio:** ~5-10% of fleet.

**Evidence requirement:** Every verified write-up (`session/04-verified/*.md`) must link back to: (a) the original candidate (`session/02-candidates/`), (b) the repro harness (`session/03-repros/`), (c) the audit reference (`archive/manifest.md` or `session/05-output.md`).
